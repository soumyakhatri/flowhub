03

Refresh access token

POST /api/v1/auth/refresh

When is it called?

  • App startup — AuthProvider restore()
  • Any API returns 401 — auto-retry once

Purpose

  • Access JWT expired (~15m) — get a new one
  • Stay logged in without re-entering password
  • Rotate refresh token (old one revoked)
